Version 0.1.2 remembers separate Male and Female devotional voices and no longer silently substitutes the default voice. Open a devotional, choose Male, select and preview an installed voice to save for Male; repeat for Female. Voice availability depends on your phone. If it only has one voice, install another in its text-to-speech settings.

Before replacing an earlier test app, export notes and encrypted journal backups. Test signing keys change between builds, so Android may require uninstalling the old test app first; uninstalling removes its local data. Import backups after installing.

No GitHub account is needed to download. Open the APK on an Android phone and tap Install. This is an early test app; audible playback needs checking on your phone. Human recordings require internet. Native background audio and lock-screen controls remain pending. Not for iPhone.

This repository contains public downloads only.

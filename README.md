# Living Word Bible — Android downloads

[Download the Android test app v0.1.1](https://github.com/Chosen0001/living-word-bible-downloads/releases/tag/v0.1.1-test)

Open the release page and select **Living-Word-Bible-Android-v0.1.1.apk** under **Assets**. No GitHub account is needed. Open the file on an Android phone and tap Install.

Version 0.1.1 adds native Android speech for devotional reading and Bible device narration, fixing the unsupported-browser audio message in the Android app.

Before replacing the earlier test app, export notes and encrypted journal backups. The test signing key has changed, so Android may require uninstalling the previous test app first; uninstalling removes its local data. Import your backups after installing.

This is an early test app. Human narration needs internet; native background audio and lock-screen controls are still pending. Audible playback needs testing on your device. The APK cannot be installed on an iPhone.

This repository contains public downloads only.

# Living Word Bible — Android downloads

[Download the Android test app](https://github.com/Chosen0001/living-word-bible-downloads/releases/tag/v0.1.0-test)

Open the release page and select **Living-Word-Bible-Android-test.apk** under **Assets**. No GitHub account is needed to download this public test release. Open the file on an Android phone and tap Install.

This is an early test app. Human narration needs internet; native background audio and lock-screen controls are still pending. The APK cannot be installed on an iPhone.

This repository contains public downloads only.
